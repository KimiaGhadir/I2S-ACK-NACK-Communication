# سیستم ارتباط I2S با مکانیزم ACK/NACK

## معرفی
در این پروژه یک سیستم ارسال و دریافت داده مبتنی بر I2S طراحی شده است که با اضافه کردن مکانیزم ACK/NACK، اطمینان انتقال داده افزایش پیدا می‌کند. هدف، تشخیص فریم‌های ناقص و مدیریت خطا در ارتباطات صوتی و دیجیتال است.

## امکانات
- پیاده‌سازی مکانیزم ACK/NACK روی I2S  
- تشخیص فریم ناقص یا خراب  
- مدیریت خطا و ارسال مجدد داده  
- شبیه‌سازی کامل در Proteus  
- کدنویسی با Embedded C  

## ابزارها و تکنولوژی‌ها
- Proteus  
- Embedded C  
- میکروکنترلرهای دارای I2S
